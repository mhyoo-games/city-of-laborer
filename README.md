# 노동자의 도시 (City of Laborer)

새벽 네 시 반, 알람이 울린다. 인력사무소 앞에는 벌써 사람들이 쪼그려 앉아 있다.
오늘 일을 받을 수 있을까? 받으면 몸으로 하루를 버티고, 일당 봉투를 받고, 포장마차에서 같이 일한 사람의 이야기를 듣는다.
그렇게 하루하루 모아 꿈 하나를 이루는 이야기입니다.

브라우저에서 바로 하는 하루살이 게임입니다. 키보드와 휴대폰 터치 둘 다 됩니다.

## 하루

1. **새벽** — 일어날까, 5분만 더 잘까, 오늘은 쉴까. 비가 오면 건설 현장은 공친다.
2. **인력사무소** — 오늘 나온 일을 보고 지원한다. 일마다 난이도(쉬움·보통·빡셈)가 있어 빡센 일은 더 주지만 현장 게임이 어렵다. 평판·숙련·늦잠·나이·행색에 따라 뽑힐 가능성이 달라진다. "처음 보는 업체"는 일당이 높지만 떼먹힐 수도 있다. 돈이 바닥나면 소장님께 가불을 부탁할 수 있다.
3. **오전 일 → 점심 → 오후 일** — 일마다 손으로 하는 짧은 현장 게임. 지치면 손이 둔해지고, 서두르면 다친다.
4. **일당 봉투** — 기본 일당, 숙련·날씨·자격증, 소개비 10%. 잘하면 다음 날 그 현장에서 지명이 들어온다.
5. **저녁** — 포장마차·밥 해 먹기·찜질방·집에 전화·자격증 공부·노동청 진정. 작업용품을 사고 학원에 등록한다.
6. **일기** — 하루 생활비, 일주일마다 방값과 꼭 나가는 돈(학자금·집 생활비·약값), 가끔 날아오는 청구서, 해낸 일에 도장.

## 살아남기

돈을 못 벌면 가난이 찾아온다.

- 생활비를 못 내면 **굶는다**. 굶으면 다음 날 기운이 덜 나고 다치기 쉽다.
- 방값이 두 주 밀리면 **고시원에서 나온다**. 찜질방(하룻밤 9,000원)에서 자고, 그 돈도 없으면 **거리**에서 잔다. 거리에서는 회복이 더디고, 씻지 못한 행색 때문에 잘 안 뽑히고, 추운 밤엔 몸살이 난다.
- 일주일 치 방값을 모으면 저녁에 **다시 내 방**으로 돌아갈 수 있다.
- 닷새를 굶거나 이레를 거리에서 자면 **쓰러진다** (처음부터 다시).
- 처음에 난이도를 고른다: **보통** 또는 **고된 삶**(물가가 비싸고 청구서가 자주 오고 현장이 거칠다).

## 여덟 가지 일

| 일 | 하는 법 |
| --- | --- |
| 현장 정리 | 방향키로 부스러기를 줍고(세 개까지) 마대에 버린다. Z로 뛰기, 지게차 피하기 |
| 택배 상하차 | 빨간 딱지 ↑, 파란 딱지 ↓, 딱지 없으면 ←. 큰 상자는 여러 번 |
| 공장 조립 라인 | 누름틀 밑에서 Z로 철컥, 빨간 불량품은 X로 빼기 |
| 배관 조공 | 방향키로 칸을 고르고 Z로 관 돌리기. 물이 오기 전에 이어 놓고 X로 밸브 열기 |
| 크레인 신호수 | ←→로 옮기고 ↓로 내리기. 흔들림이 멎었을 때 깃발 위에 |
| 벽돌 쌓기 | 오가는 벽돌을 Z로 떨어뜨려 아래 벽돌 위에 딱 맞게. 삐져나온 만큼 잘린다 |
| 함바 주방 보조 | 주문마다 뜨는 화살표를 순서대로. 틀리면 처음부터, 늦으면 손님이 간다 |
| 철근 나르기 | 어깨의 철근이 기울면 ←→로 바로잡고, 걸림돌은 ↑로 넘기 |

## 세 사람

- **청년 (27살)** — 고시원을 나와 원룸 보증금 마련하기
- **가장 (43살)** — 딸의 대학 첫 등록금 모으기
- **어르신 (63살)** — 아내와 제주도 여행 가기

## 만든 방법

- TypeScript + Canvas 2D (320×180 도트 화면) + 메뉴는 HTML. 외부 게임 엔진 없음.
- 하루 규칙(뽑히기·일당·피로·다침·자격증·이야기·저장)과 다섯 가지 현장 게임 규칙은 화면과 떨어진 순수 TS. 테스트에서 봇이 60일을 살아 보고, 현장 게임마다 "잘하면 높은 점수, 가만있거나 막 누르면 낮은 점수"인지 확인한다.
- 배경음악·효과음은 Web Audio로 합성한 새 곡.

```
npm install
npm test          # 규칙 테스트
npm run build     # dist/
```
